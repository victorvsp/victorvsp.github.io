Laboratório 5

Neste laboratório, vamos praticar a manipulação de listas ligadas. Em todos os exercícios, as listas já serão construídas pelo CodeRunner. Sua implementação vai receber as listas prontas, reorganizando os ponteiros entre os nós existentes.

Estruturas utilizadas

Nos exercícios com listas simplesmente ligadas, utilizaremos a seguinte definição de nó:

typedef struct No {
    int valor;
    struct No *prox;
} No;

O ponteiro para o primeiro nó representa a lista. Uma lista vazia é representada por NULL, e o campo prox do último nó também é NULL.

No exercício com listas duplamente ligadas, utilizaremos:

typedef struct NoDuplo {
    int valor;
    struct NoDuplo *ant;
    struct NoDuplo *prox;
} NoDuplo;

Nesse caso, cada nó aponta para o próximo nó (prox) e para o anterior (ant). O primeiro nó tem ant == NULL, e o último tem prox == NULL.

O CodeRunner já terá essas definições e criará as listas antes de chamar suas funções. Não envie as definições das estruturas nem uma função main: envie somente a implementação da função pedida em cada exercício (e de eventuais funções auxiliares que você criar).

Em todos os exercícios, você deve reorganizar os nós por meio dos ponteiros, sem modificar os campos valor e sem alocar novos nós. Também não remova nós nem libere a memória deles. Assim, todos os nós presentes nas listas de entrada devem continuar presentes na lista resultante, sem repetições.

Exercício 1 – Rotação de uma lista

Uma rotação à direita de uma posição move o último nó de uma lista para o início, mantendo a ordem relativa dos demais nós. Uma rotação à direita de k posições equivale a realizar essa operação k vezes.

Escreva uma função que rotacione uma lista simplesmente ligada k posições para a direita.

Função a implementar

No *rotacionar(No *lista, int k);

A função deve retornar o ponteiro para o primeiro nó da lista após a rotação. Considere que k >= 0. Se a lista for vazia, a função deverá retornar NULL.

Exemplos

Exemplo 1. Para a lista

0 -> 1 -> 2 -> 3 -> 4 -> NULL

uma rotação com k = 2 deve produzir

3 -> 4 -> 0 -> 1 -> 2 -> NULL

Exemplo 2. Para a lista

2 -> 0 -> 1 -> NULL

uma rotação com k = 2 deve produzir

0 -> 1 -> 2 -> NULL

Exemplo 3. Para uma lista com cinco nós, uma rotação de k = 7 posições tem o mesmo resultado que uma rotação de duas posições.

Sua função deve tratar também k = 0, listas com um único nó e valores de k maiores que o comprimento da lista.

O CodeRunner será responsável por criar a lista e chamar a função. Envie apenas a implementação de rotacionar, sem uma função main.

Exercício 2 – Intercalando duas listas

Dadas duas listas simplesmente ligadas, queremos formar uma única lista alternando os nós das duas listas: primeiro um nó da primeira lista, depois um da segunda, depois outro da primeira, e assim por diante.

Se uma das listas terminar antes da outra, os nós restantes da outra lista devem ser colocados no final, preservando sua ordem original.

Função a implementar

No *intercalar(No *a, No *b);

A função deve retornar o ponteiro para o primeiro nó da lista intercalada. Os nós das listas a e b devem ser reutilizados, então não crie uma terceira lista com novos nós. Após a operação, as duas listas originais não precisam continuar existindo como listas separadas.

Exemplos

Exemplo 1. Dadas as listas

a: 1 -> 3 -> 5 -> 7 -> NULL
b: 2 -> 4 -> 6 -> NULL

a lista resultante deve ser

1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> NULL

Exemplo 2. Dadas as listas

a: 10 -> 20 -> NULL
b: 1 -> 2 -> 3 -> 4 -> NULL

a lista resultante deve ser

10 -> 1 -> 20 -> 2 -> 3 -> 4 -> NULL

Sua função também deve funcionar quando uma ou ambas as listas forem vazias.

O CodeRunner será responsável por criar as duas listas e chamar a função. Envie apenas a implementação de intercalar, sem uma função main.

Exercício 3 – Reorganizando uma lista pelas extremidades

Neste exercício, vamos trabalhar com uma lista duplamente ligada. Queremos reorganizar os nós alternando elementos do início e do final da lista: primeiro o primeiro nó, depois o último, depois o segundo, depois o penúltimo, e assim sucessivamente, até incluir todos os nós.

Função a implementar

NoDuplo *reorganizar(NoDuplo *lista);

A função deve retornar o ponteiro para o primeiro nó da lista reorganizada. Você deve atualizar corretamente ambos os ponteiros, ant e prox, de cada nó, de modo que seja possível percorrer a lista resultante nos dois sentidos.

Exemplos

Exemplo 1 – Quantidade par de nós. A lista

NULL <- 1 <-> 2 <-> 3 <-> 4 <-> 5 <-> 6 -> NULL

deve ser reorganizada como

NULL <- 1 <-> 6 <-> 2 <-> 5 <-> 3 <-> 4 -> NULL

Exemplo 2 – Quantidade ímpar de nós. A lista

NULL <- 1 <-> 2 <-> 3 <-> 4 <-> 5 -> NULL

deve ser reorganizada como

NULL <- 1 <-> 5 <-> 2 <-> 4 <-> 3 -> NULL

Sua função deve tratar também listas vazias e listas com um ou dois nós. Depois da reorganização, o primeiro nó deve ter ant == NULL, o último deve ter prox == NULL, e os ponteiros de nós consecutivos devem ser consistentes entre si.

O CodeRunner será responsável por construir a lista duplamente ligada e chamar a função. Envie apenas a implementação de reorganizar, sem uma função main.

Nota

Sugestão: pense em como percorrer uma lista duplamente ligada a partir das duas extremidades, usando um ponteiro para o início e outro para o final.

Testando suas funções localmente

O arquivo lab5_teste_local.c, fornecido junto com este enunciado, contém as mesmas definições de No e NoDuplo utilizadas pelo CodeRunner, além de funções auxiliares para construir, imprimir e liberar listas, e uma função main com exemplos de testes dos três exercícios.

O arquivo contém declarações das funções rotacionar, intercalar e reorganizar. Para usá-lo, adicione suas implementações antes da função main (ou antes das funções de teste) e compile o programa.

Para compilar com GCC:

gcc -Wall -Wextra -g -fsanitize=address,undefined \
    lab5_teste_local.c -o lab5_teste

O programa imprime os resultados das operações e, no exercício 3, percorre a lista também no sentido inverso para ajudar a verificar os ponteiros ant. Esses são apenas alguns exemplos: teste também listas pequenas, listas vazias e casos especiais.

Importante: o arquivo de testes é apenas para uso local. Na submissão de cada exercício ao CodeRunner, envie somente a função solicitada e eventuais funções auxiliares. Não inclua main, as funções de construção e impressão das listas ou as definições das estruturas.
