Breve introdução ao Linux e ao terminal

O que é Linux?

Linux é uma família de sistemas operacionais de código aberto

Construídos em torno do Kernel Linux, criado por Linus Torvalds em 1991

Unix-like: segue a organização e as principais convenções dos sistemas Unix (arquivos hierárquico, permissões, shells, etc.)


Uma distribuição Linux é um sistema operacional completo

Inclui kernel, utilitários, bibliotecas e aplicativos

Exemplos: Ubuntu, Fedora, Debian, Arch Linux, etc.

Aulas e laboratórios serão realizados em ambiente Linux. Detalhes para outros sistemas operacionais não devem ser difíceis de encontrar.

Diretórios e arquivos

O sistema de arquivos Linux é organizado em diretórios e arquivos

  • Cada diretório pode conter arquivos e outros diretórios (subdiretórios)
  • Todos os arquivos e diretórios estão contidos no diretório raiz / (root)
  • A sequência de diretórios até arquivo é chamada de caminho (path)


/
├─ home   
│  └─ user1
      └─ prog_estruturada
         └─ slides.pdf

Caminho: /home/user1/prog_estruturada/slides.pdf

Endereçamento relativo

Cada diretório (e arquivo) pode ser endereçado listando o caminho de diretórios relativo a pasta atual

  • Diretório atual: . (ponto)
  • Diretório superior: .. (dois pontos)
  • Diretório home do usuário: ~ (til)

Exemplo se o diretório atual é /home/user1:

  • prog_estruturada/slides.pdf é o caminho relativo
  • ../user2/arquivo.txt é o caminho relativo para um arquivo em outro diretório

Interface de linha de comando e terminal

Em sistemas Unix-like, é muito comum interagir com o sistema por meio de uma interface de linha de comando (command-line interface ou CLI).

  • O terminal é o ambiente no qual digitamos comandos e vemos sua saída.

  • O programa que interpreta esses comandos é chamado de shell.

  • No Linux, um dos shells mais comuns é o Bash

    • Os comandos são iguais ou muito semelhantes na maioria dos shells.

  • A linha de comando é especialmente conveniente para programadores e administradores de sistemas (e agentes de IA).

Alguns comandos básicos

A sintaxe da linha de commando frequentemente é

nome_do_comando [opções] [argumentos]

O comando pode ser algum comando do shell ou um programa externo. Alguns comandos básicos:

  • cd [bla]: muda o diretório atual para aquele em bla
  • ls: lista os arquivos e diretórios no diretório atual
  • pwd: exibe o caminho do diretório atual
  • mkdir [nome]: cria um novo diretório com o nome especificado
  • rm [arquivo]: remove um arquivo
  • cp [origem] [destino]: copia um arquivo de uma localização para outra
  • mv [origem] [destino]: move ou renomeia um arquivo

Dicas sobre o terminal

Algumas dicas do terminal

  • Use Ctrl+C para interromper um comando em execução
  • Use man <comando> para ver o manual do comando. Exemplo: man ls
  • Mutios comandos aceitam --help para exibir ajuda rápida
  • Use a tecla Tab para completar nomes de arquivos e diretórios
  • Use as setas para cima/baixo para navegar pelo histórico de comandos
  • Use Ctrl+R para buscar comandos anteriores no histórico

Algoritmos e programação em linguagens de alto nível

Algoritmos

Um algoritmo é uma sequência de etapas bem definidas para realizar uma tarefa.


Exemplos:

  • Verificar se um número é primo;
  • Ordenar uma lista de números;
  • Encontrar uma palavra em um arquivo de texto.

Computador e instruções

A CPU (Central Processing Unit) executa sequências de instruções.


Cada CPU possui um conjunto finito de instruções que varia com a arquitetura (x86, ARM, etc.)

Conhecido como linguagem de máquina


Podemos descrever algoritmos em linguagm de máquina, gerando um programa.

Linguagens de programação

Uma linguagem de programação é uma linguagem com regras precisas usada para descrever operações que um computador pode exercutar.


Inicialmente, existia somente as intruções da CPU

Programas simples já são complexos de se descrever com tais intruções.


Linguagens de alto nível: Linguagens mais expressivas, com maiores abstrações servindo como intermediárias entre o programador e a linguagem de máquina.

Linguagens compiladas e interpretadas

Modos como as linguagens de programação são executadas:

  • Compiladas: um compilador traduz o código-fonte para código de máquina (executável).
  • Interpretadas: Um outro programa (interpretador) executa o código-fonte diretamente.

Essa distinção pode ser mais sutil por uso de máquinas virtuais e compilação just-in-time, por exemplo. C é um exemplo clássico de linguagem normalmente compilada para código nativo.

Paradigmas de programação

Linguagens também podem ser classificadas por paradigma.

  • Estruturado: C
  • Orientado a objetos: Java, C++, Python
  • Funcional: Haskell, OCaml, partes de Python/JavaScript
  • Lógico: Prolog

Compilação

O que é compilação?

Compilar é traduzir um programa de uma linguagem para outra.

Existe diversos compiladores de C: gcc, clang, etc.

Programas executáveis são específicos da plataforma (sistema operacional, arquitetura, etc.)

Compilação de múltiplos arquivos

É possível compilar um programa a partir de diversos arquivos-fonte

Cada arquivo fonte gera um arquivos-objeto (executáveis com partes faltando)

Arquivos-objeto são ligados (linked) gerando o executável final.

Código-fonte e executável

#include <stdio.h>

int main() {
    printf("Hello World!\n");
    return 0;
}


Flags úteis e/ou recomendadas do gcc

Flags recomendadas:

  • -Wall: dá mais warnings de compilação (muito recomendado)
  • -Wextra: dá warnings adicionais de compilação
  • -Wpedantic: avisa sobre construções fora do padrão ISO C escolhido

Flags adicionais úteis:

  • -Werror: warnings viram erros de compilação
  • -g: permite usar gdb e valgrind (mas deixa programa mais pesado)
  • -lm: permite usar funções matemáticas

Exemplo de compilação recomendada:

gcc -Wall -Wextra -Wpedantic programa.c -o programa

Linguagem C

Linguagem C

A linguagem C foi criada por Dennis Ritchie no início dos anos 1970.

Alguns marcos/padrões importantes:

  • K&R C, associado ao livro de Kernighan e Ritchie;
  • C89/C90;
  • C99;
  • C11;
  • C17/C18;
  • C23.

Por que estudar C?

C continua importante porque aparece em contextos como, sistemas operacionais, compiladores, sistemas embarcado, etc.


Além disso, C nos força a entender conceitos que outras linguagens escondem parcialmente, como:

  • endereços de memória;
  • alocação dinâmica;
  • representação dos dados.

Popularidade de linguagens

Primeiro programa

Programa mínimo em C

#include <stdio.h>

int main() {
    printf("Hello World!\n");
    return 0;
}

Para compilar:

gcc teste.c -o teste

Para executar:

./teste

Um programa ainda menor

int main() {
    return 0;
}

Esse programa não imprime nada, mas é um programa C válido.


A função main é o que vai ser executado quando o programa é iniciado.


O return 0; indica, por convenção, que o programa terminou com sucesso.

Valores diferentes indicam diferentes tipos de erro

Tipos de dados

Tipo Tamanho típico Faixa típica
char 1 byte -128 a 127
short int 2 bytes \(-2^{15}\) a \(2^{15}-1\)
int 4 bytes \(-2^{31}\) a \(2^{31}-1\)
long int 8 bytes \(-2^{63}\) a \(2^{63}-1\)
long long int 8 bytes \(-2^{63}\) a \(2^{63}-1\)
float 4 bytes ~7 casas de precisão
double 8 bytes ~15–16 casas precisão

Tamanhos/faixas exatapas dependem do compilador/sistema. Valores acima são típicos para gcc em sistemas Linux de 64 bits.

Atenção aos limites

Tipos numéricos têm limites.

  • Um int não representa todos os inteiros matemáticos.
  • Um float/double não representa todos os números reais.
  • Operações podem sofrer overflow, perda de precisão ou truncamento.

Vamos usar o computador não apenas como uma calculadora, mas como uma máquina com representações finitas.

Declaração de variáveis

int main() {
    int num_matricula = 1234;
    return 0;
}

C diferencia maiúsculas de minúsculas

C é case-sensitive.

int num_matricula = 1234;
int Num_matricula = 5678;

Os nomes num_matricula e Num_matricula são diferentes.

Use nomes representativos. Evite nomes como tmp1, tmp2, aux50, exceto em situações muito locais e claras.

Entrada e saída

Biblioteca padrão de entrada e saída

Em C, usamos funções para entrada e saída.

As funções mais básicas ficam em stdio.h.

#include <stdio.h>

Durante o curso, praticamente todos os programas usarão essa biblioteca.

Saída com printf

#include <stdio.h>

int main() {
    printf("ABC\n");
    return 0;
}

A função printf imprime texto formatado.

int printf(const char *format, ...);

A string format descreve como imprimir os valores.

Exemplos de printf

#include <stdio.h>

int main() {
    int num = 507;

    printf("ABC");
    printf("%d", num);
    printf("%d\n", num);
    printf("A sala do professor eh a %d\n", num);
    printf("%c + %c = %d\n", 'A', 'B', num);

    return 0;
}

Alguns especificadores de formato

Especificador Tipo
%d int
%ld long int
%lld long long int
%f float/double em printf
%lf double em scanf
%c char
%s string
%p ponteiro/endereço

Alguns detalhes de formatação serão refinados ao longo do curso. Por enquanto, o essencial é saber imprimir inteiros, reais, caracteres e strings simples.

Entrada com scanf

Para ler valores, usamos scanf.

int scanf(const char *format, ...);

A diferença crucial:

  • printf recebe os valores a imprimir;
  • scanf recebe os endereços das variáveis onde deve escrever.

Exemplo de scanf

#include <stdio.h>

int main() {
    int num_int;

    printf("Digite um numero inteiro:\n");
    scanf("%d", &num_int);

    printf("O numero eh %d\n", num_int);
    return 0;
}

O operador & obtém o endereço da variável.

Quando estudarmos ponteiros, isso ficará muito mais claro.

Mais exemplos de leitura

#include <stdio.h>

int main() {
    int num_int;
    double num_frac;
    int a, b;

    printf("Digite um numero inteiro:\n");
    scanf("%d", &num_int);

    printf("Digite um numero fracionario:\n");
    scanf("%lf", &num_frac);

    printf("INT=%d DOUBLE=%lf\n", num_int, num_frac);

    printf("Digite dois numeros:\n");
    scanf("%d %d", &a, &b);
    printf("A=%d B=%d\n", a, b);

    return 0;
}

sizeof

Para verificar quantos bytes uma variável ou tipo ocupa, usamos sizeof.

#include <stdio.h>

int main() {
    int a;
    long int b;
    long long int c;
    float d;
    double e;
    char f;

    printf("%zu %zu %zu %zu %zu %zu\n",
           sizeof a,
           sizeof b,
           sizeof c,
           sizeof d,
           sizeof e,
           sizeof f);

    return 0;
}

O tipo do resultado de sizeof é size_t. Por isso, usamos %zu em printf.

Conversões e expressões

Conversão de tipo: primeiro exemplo

Qual é a saída?

#include <stdio.h>

int main() {
    float num;

    num = 4 / 2;
    printf("%.2f\n", num);

    num = 10 / 2.5;
    printf("%.2f\n", num);

    return 0;
}
2.00
4.00

Inteiros versus ponto flutuante

Qual é a saída?

#include <stdio.h>

int main() {
    float num;

    num = 4 / 2;
    printf("%.2f\n", num);

    num = 5 / 2;
    printf("%.2f\n", num);

    return 0;
}
2.00
2.00

Divisão inteira

Em C:

5 / 2

é uma divisão entre inteiros, cujo resultado inteiro é 2.

Para obter um resultado fracionário:

5 / 2.0
5 / ((float) 2)
((float) 5) / 2

Conversões perigosas

Conversões de um tipo com maior faixa/precisão para um tipo com menor faixa/precisão podem perder informação.

int n1 = 50000;
short int n2 = n1;

O resultado depende dos limites do tipo short int na implementação.

A mensagem importante para os alunos: conversões não são apenas uma formalidade sintática; elas podem mudar o valor armazenado.

Conversão de reais para inteiros

#include <stdio.h>

int main() {
    float f1 = 2.782;
    int n2 = f1;

    printf("%d\n", n2);
    return 0;
}
2

A parte fracionária é descartada.

Cast explícito

Podemos forçar algumas conversões com cast.

float n = (float) 507;
int t = (int) n;

Mas usar cast não torna uma conversão necessariamente segura.

Precedência do cast

Qual é a saída?

#include <stdio.h>

int main() {
    float r1 = 7 / 2;
    float r2 = ((float) 7) / 2;
    float r3 = 7 / ((float) 2);
    float r4 = ((float) 7) / ((float) 2);
    float r5 = (float) 7 / 2;
    float r6 = (float) (7 / 2);

    printf("%.1f %.1f %.1f\n", r1, r2, r3);
    printf("%.1f %.1f %.1f\n", r4, r5, r6);

    return 0;
}

Precedência do cast: resposta

3.0 3.5 3.5
3.5 3.5 3.0

O cast tem precedência alta.

A expressão

(float) (7 / 2)

primeiro calcula 7 / 2 como divisão inteira e só depois converte o resultado para float.

Inicialização e erros comuns

Sempre inicialize variáveis

Quando uma variável local é declarada, o programa reserva espaço de memória para ela.

Esse espaço não é necessariamente inicializado.

#include <stdio.h>

int main() {
    int num;
    printf("%d\n", num);
    return 0;
}

O programa pode imprimir um valor arbitrário.

Compilador como aliado

Compilando com warnings:

gcc -Wall -Wextra teste.c -o teste

O compilador pode avisar sobre problemas como uso de variável não inicializada.

teste.c: In function 'main':
teste.c: warning: 'num' is used uninitialized

Durante o curso, tratem warnings como sinais importantes. Código que compila com warnings pode estar errado.

Condicionais

Atenção: = versus ==

Qual é a saída?

#include <stdio.h>

int main() {
    int n = 507;

    if (n = 5)
        printf("n eh 5.\n");
    else
        printf("n nao eh 5.\n");

    return 0;
}

= versus ==: resposta

O código compila, mas está errado.

if (n = 5)

faz uma atribuição.

O teste de igualdade seria:

if (n == 5)

Com warnings ativados, o compilador pode ajudar a detectar esse tipo de erro.

Um erro comum com for

Qual é o problema?

int i;
for (I = 0; I < 3; I++) {
    printf("%d\n", i);
}

I e i são identificadores diferentes. O código não compila.

Estilo e padrões

Estilo de codificação

Observe o estilo adotado nos exemplos.

  • indentação consistente;
  • nomes de variáveis representativos;
  • posição das chaves consistente;
  • uma ideia por bloco de código;
  • clareza acima de compactação.

Código é escrito para duas audiências: o computador e as pessoas que precisam ler, corrigir ou modificar esse código — incluindo você no futuro.

Padrões recorrentes

Ao programar, veremos muitos padrões repetidos.

  • programa mínimo;
  • leitura de uma quantidade conhecida de valores;
  • leitura até sentinela/fim de entrada;
  • acumuladores;
  • manter maior/menor valor visto até agora;
  • contadores;
  • menus simples.

Exemplos finais

Leitura de n elementos

#include <stdio.h>

int main() {
    int qtd;
    scanf("%d", &qtd);

    for (int i = 0; i < qtd; i++) {
        int numero;
        scanf("%d", &numero);

        // Faz alguma coisa com numero
        printf("Leu numero!\n");
    }

    printf("Saiu!\n");
    return 0;
}

Leitura até sentinela

#include <stdio.h>

int main() {
    int numero;
    scanf("%d", &numero);

    while (numero >= 0) {
        // Faz alguma coisa com numero
        printf("Leu numero!\n");
        scanf("%d", &numero);
    }

    printf("Saiu!\n");
    return 0;
}

Aqui, um número negativo encerra a leitura.

Exercício 1

Faça um programa que leia um inteiro e imprima todos os divisores desse número.

Neste exercício, um divisor é um número que divide o outro com resto zero.

Exercício 2 — Lista de números 1

Faça um programa que leia um número n.

Depois, o programa deve ler n números.

Ao final, considerando os n números, o programa deve imprimir:

  • maior número;
  • menor número;
  • soma de todos os números.

Não use vetor/array neste exercício.

Exercício 3 — Lista de números 2

Modifique o programa anterior para não solicitar a quantidade n no início.

Agora, o programa deve ler números até que o usuário digite um número negativo.

Ao final, imprima:

  • maior número;
  • menor número;
  • soma de todos os números.

Exercício 4

Faça um programa que leia um número n.

Depois, o programa deve ler n números.

Ao final, considerando esses números, imprima:

  • quantos são pares;
  • quantos são ímpares.

Exercício 5 — Menu de operações

Faça um programa com um menu de operações.

O programa deve ler um código:

  • 1: soma dois números;
  • 2: soma três números;
  • 3: multiplica dois números;
  • 0: sair.

Se o usuário escolher sair, o programa imprime o menor resultado obtido e encerra.

Caso contrário, lê os números necessários, imprime o resultado da operação e volta ao menu.
